Architecture Overview

The service uses a Playwright-based headless browser to render HTML to PDF with full CSS support, including backgrounds, fonts, and print media queries.

CLI Usage

Convert any HTML file with a single command:

node cli.js input.html -o output.pdf --format A4

Key Features

  • Playwright + Chromium for accurate rendering
  • BrowserContext isolation per job (no cross-job leaks)
  • Resource blocking (images, tracking scripts, web fonts)
  • Auto-chunking for 1000+ page documents via pdf-lib merge
  • Parallel chunk rendering with p-limit concurrency control
